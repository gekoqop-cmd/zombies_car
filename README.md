# RUSTWAVE — «Выживи любой ценой»

Браузерная top-down игра на Unity для **Яндекс Игр**. Главный герой защищает свою машину на заброшенной стоянке у мастерской от волн зомби.

Карта «Город» есть в двух вариантах: **Map01** — вечер, **Map02** — ночь.

- Движок: **Unity 6000.6.1f1**, URP 17, Input System, Cinemachine 3, TextMeshPro.
- Платформа: **WebGL**. Сборка оптимизирована под размер (Brotli, stripping, crunch).
- Правила площадки: [`yandex-games-sdk.md`](yandex-games-sdk.md). **SDK Яндекс Игр подключён** (см. ниже).

---

## Что есть в игре

**Игрок**
- 2D-спрайт в 3D-сцене. Кадры вырезаны из видео `refsanim/Player/*.mp4`: idle, бег, выстрел, перезарядка.
- Автоматическая стрельба. Перезарядка по `R` или когда пуст магазин.
- Вспышка у дула, дымок и звуки.
- **Топор** — второе оружие ближнего боя: удар по дуге 160° перед игроком (2 м, 40 урона, отбрасывание), замах над головой и белый «комикс»-серп. Ломает и взрывные бочки. Когда патроны кончились совсем, топор достаётся сам, а ружьё возвращается, как только патроны появятся. Пока топор в руке, персонаж рисуется без автомата (кадры `Player_NoGun_*`, см. `Editor/PlayerGunMask.cs`).
- **Патронов мало** (магазин 20, запас 60 / максимум 100): патроны надо беречь, топор — полноценное оружие.
- Уровни за опыт: на каждом новом уровне игра встаёт на паузу и предлагает 3 случайные карточки (оружие, топор, выживание, забег). Улучшения машины — только в мастерской. Здоровье — одна карточка «ЖИВУЧЕСТЬ» (+10 / 15 / 20 / 25 к максимуму и столько же лечения сразу); полного лечения картой нет (для этого аптечки мастерской).
- **Легендарные карточки** (сразу на максимуме, золотая рамка): «ЗОЛОТАЯ ЛИХОРАДКА» — точно придёт с 5-го уровня; «ВАМПИРИЗМ» (6 здоровья за убийство) — изредка с 7-го уровня, берётся **за рекламу** (значок рекламы в углу карточки). Кнопка «ПОМЕНЯТЬ» внизу слева — новые карточки за рекламу.
- **Обучение** в первом забеге: карточки-подсказки и живые подсказки по ходу. Живые подсказки идут только в забеге с обучением (или после «ОБУЧЕНИЕ» в настройках) и больше не повторяются, даже если какая-то так и не понадобилась.
- **Серия убийств**: убийства подряд (не дольше 3 с между ними) без полученного урона — «СЕРИЯ N» под плашкой волны; с 10 убийств детали ×1.25, с 25 — ×1.5, с 50 — ×2. Удар по игроку серию обрывает.
- **Ощущение удара**: тряска камеры от полученного урона, короткая «стоп-кадр» пауза на сильных ударах (урон по игроку от 12, удар топора, смерть босса), вибрация на телефоне. На телефоне всё это выключается в настройках («ТРЯСКА И ВИБРАЦИЯ», рядом с джойстиками). На компьютере такого переключателя нет: тряска там включена всегда (`SettingsService.ShakeEnabled`).
- Шаги — мягкие синтезированные (`Editor/FootstepSynth.cs`, `Audio/SFX/Player_StepSoft1..4.wav`), тише прежних.

**Машина**
- 400 HP, прокачка в **мастерской** между волнами за металлолом с зомби: броня (8 уровней, 4 → 7,5%, всего 46%), корпус (8, всего +460), шипы (6), электроразряд (5), оружейный ящик (6, всего +330 к запасу). Вся мастерская стоит ~15 500 деталей — обычный забег докачивает машину к 25–28 волне (раньше всё было куплено к 10–15). Прокачанное до конца показывает золотую плашку **MAX**.
- **Расходники мастерской — за рекламу с вознаграждением:**
  - **аптечка** — в инвентарь (до 5), лечит полностью по клавише `3` или слоту в HUD;
  - **ремонт машины** — полностью восстанавливает прочность, 3 раза за забег;
  - **мины** — все 8 мест вокруг машины (докладываются только недостающие), 4 раза за забег.
- **Шипы** видны на модели: каждый уровень добавляет набор стальных шипов (передний бампер, задний, борта, второй ряд), новый набор «вырастает» из кузова (`Car/CarSpikesView.cs`, модель — `PrefabBuilder.BuildCarSpikes`).
- Три стадии повреждений: Intact → Damaged (≤350) → Wrecked (≤250), с дымом из-под капота.
- Компактная плашка прочности лежит на кузове. Полупрозрачна в покое и почти исчезает, когда под ней зомби или игрок. Цвет полосы совпадает со стадией повреждений, в том числе после прокачки корпуса.
- Удар зомби по машине — звук и сообщение «МАШИНУ АТАКУЮТ!» в HUD.
- **Патроны у машины**: между волнами (один раз за перерыв) `E` у машины пополняет магазин и запас до максимума.
- Пули сквозь машину и укрытия не проходят.

**Зомби и волны**
- Шесть типов зомби и три босса: волна 10 — «МАТКА» (зовёт свиту), 20 — «ТАРАН» (кислота и таран), 30 — «ЖНЕЦ» (всё сразу, ярость, удар по земле). Перед боем карточка босса с его способностями ждёт «В БОЙ!»; полоса здоровья босса — в плашке волны. У боссов своя музыка и звуки.
- Для пуль у зомби увеличенный хитбокс-триггер (+0,25 м); атака зомби и урон по площади считаются по телу.
- 30 волн по `WaveConfig`: отсчёт, спавн, перерыв 25 с между волнами (заглянуть в мастерскую, пополнить патроны). В перерыве плашка волны пишет «ПЕРЕРЫВ» (а не номер следующей волны). Перерыв можно пропустить: «ПРОПУСТИТЬ ПЕРЕРЫВ [E]» внизу экрана (на телефоне — тап); если патроны у машины ещё не взяты, кнопка сначала напоминает «ПОПОЛНИ ПАТРОНЫ У МАШИНЫ :)», потом «ТЫ БУДЕШЬ БЕЗ ПАТРОНОВ?», и только на третье нажатие — «НУ ЛАДНО...» и волна.
- **Боссы роняют лут** (`Props/LootDropper.cs`): за каждые 10% потерянного здоровья босс выбрасывает ящик патронов (+35 в запас) — финального босса можно добить из ружья. Детали с 1-го и 2-го босса (150 / 350) разлетаются по земле кусками с золотыми лучами: подошёл — кусок летит в игрока, а его иконка — в счётчик деталей, счётчик растёт, когда она долетела (`UI/LootFlyView.cs`). Что осталось лежать, само прилетает к игроку со следующей волной. Финальный босс (1000) платит сразу — забег заканчивается.
- Перед атаками боссов — кольца и линии на земле, круги приземления кислоты; на замахе босс пульсирует красным.
- Конец забега — экран победы или поражения (заработано, уровень, убито, «Заново» / «В меню»), воскрешение за рекламу один раз за забег, ×2 монет за рекламу. После поражения на «Лёгком» / «Среднем» с сохранением кнопка «Заново» становится «С ВОЛНЫ 11» (21).
- Металлолом: 4–6 с обычного зомби, 30 с громилы, 150 / 350 / 1000 с боссов, плюс награда за волну (`ProgressionConfig`), умноженные на сложность. Остаток в конце забега меняется на монеты: 50 деталей = 1 монета.

**Сложность** (`Core/Difficulty.cs`, выбирается после «ИГРАТЬ» на карте). На карточке — только главное: какие зомби и есть ли сохранения. Под карточками кнопка «КАК РАБОТАЮТ СОХРАНЕНИЯ?» с коротким объяснением для игрока: сохранение автоматическое, после боссов 10-й и 20-й волны; продолжить — выбрать ту же сложность и нажать «ПРОДОЛЖИТЬ».
| | Лёгкий | Средний | Хардкор |
|---|---|---|---|
| Здоровье / урон зомби | ×0.75 / ×0.75 | ×1 | ×1.35 / ×1.3 |
| Количество зомби | ×0.85 | ×1 | ×1.3 |
| Детали / монеты | ×0.85 / ×0.75 | ×1 | ×1.25 / ×1.6 |
| Сохранения | после боссов | после боссов | нет |
| Лидерборд | `bestTimeEasy` | `bestTimeNormal` | `bestTimeHardcore` |

- Экран выбора: три карточки (добряк — зелёный, средний — оранжевый, демон — красный; лица рисует `Editor/UiIconPainter.cs`), на карточке с сохранением — «СОХРАНЕНИЕ: ВОЛНА 11».
- **Чекпоинты** (Лёгкий, Средний; `Progression/RunSetup.cs`): после босса 10-й и 20-й волны забег сохраняется (карточки, уровни мастерской, детали — и те, что ещё лежат на земле, — аптечки, убийства, уровень, время), сразу платятся монеты этапа и показывается «ЭТАП 1 ИЗ 3 ПРОЙДЕН!» с «ПРОДОЛЖИТЬ» / «В МЕНЮ». В следующий раз — «ЕСТЬ СОХРАНЕНИЕ»: продолжить с 11 (21) волны или начать с начала. Монеты в конце забега считаются от последнего чекпоинта (`Progression/CoinRules.cs`) — переигрывание этапа не платит дважды.
- **Хардкор** — все 30 волн за раз, без сохранений. В первый раз: «В этом режиме нет сохранений… Вы уверены?» (ДА / НАЗАД), затем «ТОЧНО?)» с одной большой трясущейся «ДА» без пути назад; больше не спрашивается.
- Перед волнами каждого забега на весь экран — «РЕЖИМ: ХАРДКОР» и что он значит.
- Победа на хардкоре открывает достижение **«БЕЗУМЕЦ!»** (676 монет) — уведомление выезжает сверху поверх «Город спасён»; награду забирают в меню «ДОСТИЖЕНИЯ».
- Красные бочки взрываются в комикс-стиле («БУМ!», звёзды, вспышка, тряска экрана), убивают зомби рядом, взрывают соседние бочки; после волны возвращаются. У бочек увеличенный хитбокс для пуль (триггер +0,35 м), курсор рядом с бочкой доводит прицел на неё. Взрываются и красные бочки у мастерской.

**Камера**
- Cinemachine с небольшим опережением по движению и к прицелу.
- Не выходит за границы карты.

**Меню**
- Фон и логотип.
- Кнопки «Играть», «Настройки», «Кейсы» | «Скины», «Лидеры» | «Достижения», «Ежедневные бонусы» и счёт монет. Кнопки «Выход» нет — это требование Яндекса. На «Достижениях», «Бонусах» и «Кейсах» загорается «!», когда там что-то ждёт (на «Кейсах» — неоткрытый бесплатный кейс).
- **Кейсы**: оружейный (раскраски автомата), топоров, пуль (цвет трассера, размер, светящийся след). Открываются за монеты (даются в конце каждого забега: 1 за 5 убийств, 2 за волну, 250 за победу, плюс обмен оставшегося металлолома, всё × сложность; `Progression/CoinRules.cs`) — кнопка «150 •» с монеткой — или за просмотр рекламы (кнопка внизу карточки). Шансы редкостей — под одним общим «?» над кейсами по центру (55 / 30 / 12 / 3 %, окно закрывается повторным нажатием); на карточке — плашка бонуса легендарного скина, кнопка за рекламу того же размера, что и «купить». Рулетка останавливается на призе; повтор возвращает 40 % цены. Полученные скины надеваются в меню **«СКИНЫ»** (вкладки персонажей и коллекций). Легендарные скины дают бонус в забеге; на кейсе он скрыт («???»), пока скин не выпал. Данные — `Editor/CosmeticsBuilder.cs` → `Data/Cosmetics`; прогресс игрока — `Core/MetaProgress.cs` (см. «Сохранения»).
- Выбор карты: карточка «Город» с переключателем День/Ночь; «Ферма» закрыта. «ИГРАТЬ» открывает выбор сложности (см. «Сложность»).
- **Ежедневные бонусы** (`UI/DailyBonusPanel.cs`): 7 дней по кругу:
  - 1-й день — **бесплатный кейс**. Он копится в «КЕЙСАХ» (`MetaProgress.FreeCases`, сохраняется и в облаке), игрок сам выбирает, какой кейс открыть: вместо цены на кнопках «ОТКРЫТЬ», сверху «БЕСПЛАТНЫЙ КЕЙС — ВЫБЕРИ ЛЮБОЙ!»;
  - 2–4-й и 6-й дни — 35, 50, 70, 120 монет;
  - 5-й день — **ЛЕГЕНДАРНЫЙ КЕЙС**: золотая рулетка (золотая рамка, лучи, надпись «ЛЕГЕНДАРНЫЙ КЕЙС») из всех легендарных скинов всех кейсов. Выпадает скин, которого у игрока ещё нет; если собраны все, даётся 300 монет;
  - 7-й день — эксклюзивные **ЧЁРНЫЕ** пули (`bullet_black`). В кейсах их нет (`CosmeticItem.IsExclusive`). Выглядят как остальные скины пуль: чёрный трассер и фиолетовый светящийся шлейф, плюс фиолетовая светящаяся обводка вокруг пули (`CosmeticItem.Outline` — оболочка `Outline`, у которой рисуется только внутренняя сторона, `M_BulletOutline`). Бонус: **+1 к пробитию зомби** с начала забега, как карточка пробития. Если пули уже есть — 300 монет.

  Пропущенный день не сбрасывает ряд: он ждёт на том же дне.
- **Достижения** (`UI/AchievementsPanel.cs`, `Core/Achievements.cs`): пока одно — «БЕЗУМЕЦ!» (все 30 волн на хардкоре), 676 монет. Пока не получено — серое, с замком, но награда видна; открытое — награда светится, её забирают нажатием.

**HUD**
- Анимированный портрет, здоровье (цифры над полосой) и уровень, волна с таймером, патроны с прогрессом перезарядки, металлолом.
- Урон на полосах здоровья игрока и босса оставляет серый след, который плавно убывает (`UI/DamageTrailBar.cs`).
- Слоты справа сверху вниз: 1 — ружьё, 2 — топор, 3 — аптечка (n/5). Баннеры волн и боссов, подсказка «НАЖМИТЕ E», предупреждение «МАШИНУ АТАКУЮТ!».
- «СЕРИЯ N ×M» под плашкой волны, баннер режима перед волнами, окно «ЭТАП ПРОЙДЕН», иконки подобранного лута, летящие в счётчики.

**Звук**
- Музыка меню, дня, ночи и боссов с плавными переходами; с 25-й волны, с боссом и особенно с разъярённым боссом музыка становится напряжённее (чуть быстрее и громче, `Core/MusicDirector.cs`); звуки UI, покупки, уровня, волн, победы/поражения, боссов, взрывов, топора, пополнения патронов, ударов по машине и по игроку. Всё идёт через группы AudioMixer (Master / Music / SFX). Звуки и музыка синтезированы `tools/audio/`.
- Шестерёнка открывает настройки, оттуда можно выйти в меню.
- Все значения живые: это TMP-тексты и Filled-картинки, а не нарисованные числа.

**Настройки**
- Громкость: музыка и эффекты — через AudioMixer (общей громкости больше нет).
- «ТРЯСКА И ВИБРАЦИЯ»: ВКЛ / ВЫКЛ.
- Качество графики: Low / Medium / High / Ultra (Ultra — только на компьютере; на телефоне при первом запуске выбирается по FPS).

**Ночь (Map02)**
- Лунный свет и усиленные фонари со статичными пятнами света.
- Светящиеся окна мастерской.
- Фары и свет в салоне машины.
- Split toning, Bloom.

**Уровни графики**
- Low: без пост-обработки.
- Medium / High: больше эффектов и источников света.
- Ultra: Lit-материалы, SSAO, тени от ламп, пыль, плотная растительность.

**Яндекс Игры SDK** — `Assets/Plugins/WebGL/YandexSdk.jslib` + `Core/YandexSdk.cs`, SDK грузит шаблон `index.html` (`/sdk.js`) параллельно с игрой:
- `LoadingAPI.ready()` — когда показано главное меню;
- `GameplayAPI.start()/stop()` — игра идёт, пока открыта карта и ничто не ставит её на паузу (настройки, расстановка джойстиков, реклама, пауза платформы, потеря фокуса — всё через `Core/GamePause.cs`);
- `game_api_pause/resume` — пауза игры и звука по сигналу платформы;
- полноэкранная реклама в логических паузах: перед запуском карты и при выходе в меню (частоту ограничивает платформа), игра и звук на паузе во время показа;
- реклама с вознаграждением (`YandexSdk.ShowRewardedAd`): кейс, расходники мастерской, «ПОМЕНЯТЬ» карточки, легендарный вампиризм, воскрешение, ×2 монет; награда только в `onRewarded`;
- языки: русский и английский. Переключатель RU / EN в левом верхнем углу главного меню; без выбора язык берётся из Яндекс SDK. Тексты пишутся по-русски, английский подставляется при отрисовке (`Core/Loc.cs`) по таблице `Resources/Localization/en.txt`, которую собирает `python tools/loc/extract.py` из `tools/loc/en_table.py`. **Новый русский текст: добавь его перевод в `en_table.py` и перезапусти `extract.py`** (пропущенные видны в `tools/loc/missing.txt` и, после тестов с `-featureLang en`, в `unity/Logs/loc_misses.txt`);
- лидерборды — по одному на сложность: `bestTimeEasy`, `bestTimeNormal`, `bestTimeHardcore` (`UI/LeaderboardPanel.cs`, вкладки ЛЁГКИЙ / СРЕДНИЙ / ХАРДКОР). **Все три создать в консоли разработчика** (техническое название — только латиница и цифры; по возрастанию, время в секундах);
- вибрация на телефоне (`navigator.vibrate`; iOS и браузеры, где она запрещена во фрейме, молча пропускают);
- облачные сохранения (`player.getData` / `setData`), см. ниже.
- язык игрока из `environment.i18n.lang` (`YandexSdk.Language`; сейчас игра только на русском).

Вне Яндекс Игр (редактор, локальный сервер) SDK нет — все вызовы молча пропускаются.

**Сохранения** (`Core/MetaProgress.cs`): монеты, полученные и надетые скины, отметки «новый», обучение, рекорды карт (победы, лучшее время, лучшая волна, убийства, боссы), последняя сложность, чекпоинты Лёгкого / Среднего, достижения, ряд ежедневных бонусов, раскладка и размер джойстиков.
- Сразу пишутся на устройство (PlayerPrefs) и через 2 с — в облако Яндекса одним JSON под ключом `meta`; при сворачивании вкладки — сразу.
- Облако работает и для гостей, и для вошедших в аккаунт (у вошедших прогресс общий на всех устройствах).
- При запуске Boot ждёт облачную копию (до 5 с) и сливает её с локальной: скины, обучение, рекорды и достижения объединяются (берётся лучшее), монеты, надетые скины, сложность, бонусы и раскладка джойстиков — из более свежей копии (у каждой копии счётчик сохранений `revision`); чекпоинт, который есть только на этом устройстве, остаётся. Если облако недоступно, игра работает на локальных сохранениях. Старые копии без новых полей читаются как раньше.
- Громкость, качество и тряска в облако не идут — у каждого устройства свои. Раскладка джойстиков идёт: браузер во фрейме Яндекса на телефоне может стереть своё хранилище.

## Управление

| ПК | Действие |
|---|---|
| WASD | движение |
| Мышь | прицел |
| ЛКМ (удерживать) | огонь / удары топором |
| R | перезарядка |
| Q или колесо мыши | сменить оружие (ружьё ↔ топор) |
| 1 / 2 | ружьё / топор |
| 3 | аптечка из запаса |
| E | использовать: мастерская, патроны у машины; в перерыве — пропустить перерыв |

**Телефоны и планшеты** (управление в стиле Brawl Stars):

| Контрол | Действие |
|---|---|
| Левый джойстик | движение |
| Правый джойстик — потянуть | прицел по линии на земле и огонь, пока палец держит |
| Правый джойстик — быстрый тап | один выстрел (или удар топором) в ближайшего зомби, которого видно (не за машиной или стеной) |
| Кнопка с патронами | перезарядка |
| Кнопка с оружием | сменить оружие (на ней — то, что достанется) |
| Кнопка действия (над правым джойстиком) | мастерская, патроны у машины; подсвечивается, когда есть что использовать |

- Настройки → «ДЖОЙСТИКИ»: ползунок размера, кнопка «РАСПОЛОЖЕНИЕ». В режиме расположения игра на паузе, элементы перетаскиваются пальцем. Двигать их можно только ниже верхнего HUD.
- Положение и размер сохраняются для игрока («СОХРАНИТЬ» в режиме расположения) — и в облаке.
- Стик прицела ведёт туда, куда показывает палец на экране: направление переносится на землю через перспективу камеры, а не только по её повороту; пули на телефоне вылетают от персонажа по линии прицела.
- Новые кнопки добавляются в тот же список `MobileControlsLayout` и автоматически становятся перемещаемыми.
- Проверить мобильную версию на ПК: запустить редактор с `-forceMobile` или выставить `PlayerPrefs` `debug.forceMobile = 1`.
- **Качество на телефоне.** При первом запуске игра сама выбирает уровень: проверяет Medium по FPS и при нехватке опускает до Low. Ultra на телефоне нет (сохранённый Ultra играется как High).
- **Облегчение сцены на телефоне** (`Core/MobileTrim.cs`): при старте карты не рисуются предметы внутри мастерской (за стенами) и всё, что камера не может показать ни из одной точки карты (с запасом, на самом широком экране); коллизии остаются.

## Как собирается проект

Почти всё в `unity/Assets` — сцены, префабы, материалы, UI, данные — генерируется кодом из `Assets/Scripts/Editor/`. Поэтому проект всегда можно пересобрать с нуля в одинаковом виде.

| Меню Unity | Что делает |
|---|---|
| **Tools → Build Everything** | настройки проекта, шрифт, данные, материалы, префабы, все сцены, проверка сцен, скриншоты |
| **Tools → Build Prefabs** / **Build Scenes** | только префабы / только сцены |
| **Tools → Build WebGL Player** | релизная сборка в `unity/Builds/WebGL` (шаблон `Assets/WebGLTemplates/Rustwave`) |
| **Tools → Build WebGL Player (Development, with cheats)** | development-сборка с читами (Insert) в `unity/Builds/WebGL_Dev`, сразу открывается в браузере. Не для Яндекса |
| **Tools → Diagnostics → …** | Play-mode сценарии со скриншотами: UI, камера, ночь, сравнение качества, playtest |

Проверки игровых механик — `Editor/FeatureTests*.cs`, в batch-режиме: `-executeMethod ZombiCar.EditorTools.FeatureTests.Run -featureTest <сценарий>` (плюс `-featureMap night`, `-forceMobile`). Сценарии: `progression`, `sound`, `bosses`, `gameover`, `victory`, `explosions`, `axe`, `refill`, `carplate`, `hitbox`, `cheats`, `motion`, `screens` (полоса здоровья босса, карточка босса, воскрешение), `tutorial`, `economy` (MAX улучшений, расходники за рекламу — аптечки, ремонт, мины, — «поменять», обмен деталей, ×2 монет), `leaderboard` (таблица своей сложности, вкладки), `legendary` (обе легендарки, вампиризм за рекламу), `cloud` (слияние облачной и локальной копии прогресса, чекпоинты и достижения), `loot` (ящики патронов с босса, разлёт и подбор деталей, полёт к счётчику), `difficulty` (чекпоинт после босса, «ЭТАП ПРОЙДЕН», продолжение с 11 волны, хардкор, «БЕЗУМЕЦ!», экран сложности, достижения, бонусы), `mobileaim` (с `-forceMobile`: тап — один выстрел в видимую цель, диагональ стика, пули от персонажа), `feel` (тряска / стоп-кадр / вибрация и их выключатель, серия убийств, напряжённая музыка, замах босса; с `-forceMobile` — облегчение сцены). Тесты сами убирают за собой чекпоинты и ставят экран этапа на паузу только в `difficulty`. Скины — `SkinShots.Run`, мобильная версия — `MobileShots.Run -forceMobile`. Скриншоты — `Screenshots/Feature_*.png`. В редакторе те же сценарии запускаются из **Tools → Diagnostics → Feature Tests**. В чит-панели (Insert / F8) в меню есть кнопки «ЧЁРНЫЕ ПУЛИ: ПОЛУЧИТЬ И НАДЕТЬ», «+1 БЕСПЛАТНЫЙ КЕЙС», «ОТКРЫТЬ ЛЕГЕНДАРНЫЙ КЕЙС» и «ЕЖЕДНЕВНЫЙ БОНУС СНОВА ДОСТУПЕН».

**Читы для тестов — клавиша `Insert`** (`DevTools/CheatPanel.cs`, игра на паузе, пока окно открыто): каждое улучшение машины из мастерской +1 или на максимум бесплатно, «вся машина на максимум», переход на волну 10 / 20 / 30 (или следующую), +1000 металлолома, полные патроны, лечение, убить всех зомби, +1000 монет для кейсов, обучение заново. Окно есть только в редакторе и в development-сборках — в релизной сборке для Яндекса читов нет.

К боссам без прохождения волн можно и так: в Play Mode выбрать `Systems/MapSystems`, у компонента **WaveDirector** открыть меню (⋮) → **Debug → Skip to wave 10 / 20 / 30**.

> ✅ **Ручные правки карт сохраняются.** Map01/Map02 уже существуют, поэтому **Build Everything** их не пересоздаёт, а только дописывает недостающие системы забега (`SceneBuilder.PatchMap` → `AddRunSystems`: лут, `RunSetup`, `MobileTrim`). Деревья, предметы и прочий декор, расставленные руками, остаются. Пересоздать карты из кода целиком (ручные правки пропадут!) — только явно, через **Tools → Rebuild Map Scenes From Code**. Остальные сцены (Boot, MainMenu, UI_HUD) по-прежнему собираются из кода.

Сборка из командной строки ([Unity CLI](https://docs.unity.com/)):

```bash
unity run unity --editor-version 6000.6.1f1 -- -buildTarget WebGL -executeMethod ZombiCar.EditorTools.ProjectBuild.BuildAll
```

Play-mode сценарии в batch-режиме запускаются напрямую через `Unity.exe`, **без** `-quit`: сценарий сам закрывает редактор. Например:

```bash
Unity.exe -batchmode -projectPath unity -buildTarget WebGL -executeMethod ZombiCar.EditorTools.UiShots.Run
```

### Архив для Яндекс Игр

```bash
python tools/yandex/pack.py
```

Без Python — то же самое на PowerShell: `powershell -ExecutionPolicy Bypass -File tools/yandex/pack.ps1`. Архив собирается из релизной сборки (**Tools → Build WebGL Player**): в ней нет читов, они компилируются только в редакторе и development-сборке.

Скрипт собирает `unity/Builds/Rustwave_yandex.zip`: `index.html` в корне, файлы `Build/` и `TemplateData/`. Заодно проверяет требования Яндекса: размер до 100 МБ, имена без пробелов и кириллицы, только относительные пути. Этот архив загружается в консоль разработчика как черновик.

WebGL-шаблон Rustwave:
- игра на весь экран;
- без прокрутки, pull-to-refresh, выделения текста и меню долгого тапа;
- разрешение на телефонах ограничено (devicePixelRatio ≤ 1,5);
- экран загрузки с логотипом;
- подключает SDK Яндекс Игр (`/sdk.js`) и инициализирует его, пока грузятся данные игры.

Размер загрузки: текстуры сцены сжаты crunch (DXT с доп. сжатием, качество 60), UI-картинки кратны 4 (иначе Unity не сжимает их вовсе), заставка Unity отключена.

Python-инструменты (`tools/`) требуют Python 3 с `numpy`, `Pillow`, `opencv-python-headless`, `scipy`. Для моделей нужен Blender, для кадров игрока — `rembg` и `ffmpeg`.
